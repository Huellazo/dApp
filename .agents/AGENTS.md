# Workspace Agent Rules

## 🌐 Web3 Technical Terminology Policy
1. **Developer & Technical Scope (Backend, Scripts, Smart Contracts, Logs, Docs)**:
   - ALWAYS use standard **English Web3 technical terms** (e.g., `Token Mint`, `Associated Token Account (ATA)`, `Program Derived Address (PDA)`, `Keypair`, `Cross-Program Invocation (CPI)`, `SPL Token`, `Devnet RPC Endpoint`, `Airdrop`, `Transaction Signature`).
2. **User-Facing & Frontend Scope (UI Screens, Components, Modals)**:
   - NEVER expose Web3 jargon to the end user. Use clean, simple **Mexican Spanish** (e.g., `Puntos Huellazos ($HZ)`, `Estampas de Pasaporte`, `Código de Autenticidad`, `Monedero`).
