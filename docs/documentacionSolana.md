* [Mapbox](https://www.mapbox.com/): Es una plataforma de mapas interactivos que se puede implementar para mostrar la ruta turistica y los comercios locales con soporte GPS en la aplicacion movil.
* [Turfjs](https://turfjs.org/docs/getting-started): Es una libreria de analisis espacial que sirve para delimitar las zonas geograficas de interes y activar los retos de realidad aumentada cuando el usuario entre en ellas.
* [Solana Blink](https://github.com/dialectlabs/blink-starter-solana): Es una plantilla para crear enlaces interactivos que permite integrar las reservas de rutas y compras de artesanias directamente en las redes sociales del proyecto.
* [Solana Movil](https://docs.solanamobile.com/get-started/react-native/quickstart): Es la guia oficial de inicio rapido para conectar la aplicacion de React Native con el ecosistema movil de Solana y permitir firmas seguras.
* [Plantilla NFT Movil](https://github.com/solana-mobile/tutorial-apps/tree/main/MobileNFTMinter): Es un repositorio tutorial que sirve como base para configurar la emision del pasaporte digital directamente desde el dispositivo del usuario.
* [React Native Solana](https://github.com/solana-mobile/react-native-samples/tree/main/cause-pots): Es un ejemplo de codigo enfocado en fondos colectivos que ayuda a programar la logica de pools de liquidez y staking comunitario para los proyectos locales.
* [Minty Fresh](https://github.com/solana-mobile/Minty-fresh): Es una aplicacion movil que permite convertir imagenes del telefono en activos digitales y se puede usar para que los artesanos suban sus obras a la blockchain de forma sencilla.
* [Mock MWA Wallet](https://github.com/solana-mobile/mock-mwa-wallet): Es una herramienta de simulacion de billetera que sirve para realizar pruebas locales de firmas de transacciones en el entorno de desarrollo sin usar fondos reales.
* [Metaplex Bubblegum](https://www.metaplex.com/docs/smart-contracts/bubblegum): Es el programa oficial para la gestion de NFTs comprimidos que se debe integrar para emitir miles de medallas y eco sellos de viaje a un costo menor a un centavo.
* [Repo Bubblegum](https://github.com/metaplex-foundation/mpl-bubblegum): Es el codigo base del programa de compresion que sirve para estudiar la estructura tecnica profunda de los arboles de merkle concurrentes.
* [Waylearn NFT](https://github.com/WayLearnLatam/Solana-NFTs-Template): Es una plantilla en espanol para la creacion de colecciones digitales que sirve de guia para estructurar los metadatos y la distribucion de los archivos del pasaporte.
* [Solana Pay](https://solana.com/es/docs/payments/accept-payments/solana-pay): Es el estandard de pagos de la red que se utilizara para generar los codigos QR fisicos en los comercios y permitir transferencias inmediatas de USDC o SOL.
